    Executar o Atlas/RS

    A versão local executa a busca por perguntas, abre páginas dos PDFs arquivados e acompanha a curadoria. O ZIP completo requer acesso concedido ao repositório do projeto.

    1. Baixe e extraia o projeto

      Use sua conta do GitHub com acesso ao projeto. Instale também o Python 3.11 ou superior.

      Baixar ZIP do Atlas/RS ↗ Baixar Python ↗

    2. Inicie a busca

      Abra um terminal na pasta extraída. No PowerShell, execute:

      $env:PYTHONPATH = "src"
python -m curriculo_rag.web_server --port 8765

      No macOS ou Linux, use PYTHONPATH=src python3 -m curriculo_rag.web_server --port 8765. Abra 127.0.0.1:8765 no mesmo computador. Selecione a base, a estratégia e o curso. Use Ctrl+C no terminal para encerrar.

    3. Adicione Qwen e Laya

      Para HyDE e resumos extrativos, instale o Ollama e baixe o modelo com ollama pull qwen2.5:1.5b. Mantenha o Ollama aberto enquanto consulta. Para curadoria, instale o Laya e importe no Corpus o Markdown gerado em Curadoria → Exportar para Laya.

      Baixar Ollama ↗ Modelo Qwen ↗ Instalar Laya ↗

    Catálogo online

    Filtra os metadados e links oficiais no navegador. As consultas de exemplo foram executadas previamente.

    Busca local por edição

    Combina TF-IDF e grafo de proveniência. A variante experimental alterna anos documentais em comparações explícitas.

    Inspeção temporal local

    Usa rótulos curriculares e indica lacunas. Um ano de publicação ou rótulo curricular não estabelece vigência jurídica.
